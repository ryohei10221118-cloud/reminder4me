01

工具簡介

這是一款專為客服人員設計的賽事計時與快速回覆工具，幫助你在處理多場賽事客訴時，快速追蹤每張注單的處理進度，並在正確的時機發送標準化回覆。

⏱
多階段計時
自動追蹤每張注單的處理時間，時間到即彈出提醒。
💬
快速回覆
依注單狀態與語言自動產生標準回覆，一鍵複製。
📥
JSON 匯入
從後台貼上注單 JSON，自動解析賽事資訊。
📋
預設管理
儲存常用需求類型，拖曳排序，快速帶入。
🔀
批量操作
同時管理多張注單，合併同場賽事卡片。
📝
賽事記錄
為每場賽事留下備註，追蹤處理進度。
02

開始使用

直接用瀏覽器開啟 index.html 即可，無需安裝任何軟體，所有資料儲存於瀏覽器的 LocalStorage。

ℹ️
建議使用 Chrome 或 Edge 開啟以獲得最佳體驗。資料僅存在該瀏覽器，換裝置或清除瀏覽器資料後會遺失。

計時階段

每張卡片依照設定的時間分為多個階段，時間到達時會顯示提醒彈窗：

階段說明
第一次初始等待，等待相關部門回覆。
第二次第一次超時後，再次提醒跟進。
超時長時間未處理，需要立即關注。
ℹ️
提醒彈窗會自動排隊，若同時有多張卡片到期，會依序顯示，不會遺漏任何一張。

使用步驟

計時到達時彈窗自動出現；或手動按下卡片上的「重新計時」。
視窗中會顯示依語言和需求類型產生的標準回覆。
點擊回覆內容旁的📋 複製按鈕，貼到客服平台。
確認後按「重新計時」重置計時器，等待下一次提醒。
若已處理完畢，按「強制推進」跳到下一階段，或按「完成」結束。
💡
快速回覆視窗關掉後計時器仍繼續，下次提醒會再次彈出。若要跳過當前階段，使用「強制推進」按鈕。
06

JSON 匯入

從後台工具複製注單的 JSON 資料後，可以直接貼入工具，自動解析賽事名稱、投注內容與賽事狀態。

匯入步驟

按下工具右上角的「📥 JSON」按鈕，開啟匯入視窗。
將後台複製的注單 JSON 貼入文字框，工具會自動解析（無需另外按按鈕）。
解析成功後會顯示賽事選擇畫面，勾選要帶入的賽事。
按下「✓ 匯入」，賽事資訊自動帶入表單。
繼續貼入下一張注單，或按「完成」關閉視窗。

新增預設

點擊「⚙ 預設管理」展開面板。
在輸入框填入需求類型名稱，按「＋ 新增」。
建立後可拖曳調整順序，或按 ✕ 刪除。

比分顯示設定

每個預設右側有一個「比分」核取方塊。勾選後，使用這個預設建立的卡片會在卡片上顯示從 JSON 匯入的投注內容與比分資訊，方便對照處理。

💡
針對需要核對賽果的需求類型（如「結算疑問」），建議勾選「比分」，省去每次開後台工具比對的時間。
08

賽事記錄

每張計時卡片的賽事名稱旁有一個「記錄」按鈕，點擊後可為該賽事輸入備註，並複製包含備註的完整資訊。

複製記錄的內容格式

按下「📋 複製記錄」後，複製到剪貼簿的內容格式如下：

Manchester City vs Arsenal
EventId: 837017040488620032
（你在備註框輸入的內容）
ℹ️
EventId 只有在透過 JSON 匯入的賽事才會帶入。手動輸入的賽事沒有 EventId，複製內容不含此行。
09

使用技巧

處理多注單同場賽事

當兩位玩家下注同一場賽事時：

匯入第二張注單的 JSON 時，工具會偵測到相同賽事並自動詢問是否合併。
選擇「合併」後，兩張注單的號碼會合併到同一張計時卡片，方便一起回覆。

快速清空表單

按下表單右側的「清空」按鈕，可一次清除所有已填寫的資料，快速準備處理下一張注單。

一次管理多張卡片

卡片左上角的核取方塊可多選，選取後可對所有選取的卡片批量操作（批量重新計時、批量完成）。

資料持久保存

所有計時卡片和預設資料都自動儲存在瀏覽器的 LocalStorage，關閉頁面後重新開啟仍會保留。

⚠️
資料僅保存在本機瀏覽器，清除瀏覽器快取或換電腦會導致資料遺失。重要資訊請另行備份。
